# Консольная утилита обработки содержимого файлов

`ШИФТ 2025` **·** `Java` **·** `Тестовое задание`
![til](./app/assets/terminal.gif)

### Зависимости:

* **Java** 17.0.12;
* **Gradle** 8.14.3 - _система сборки_;
* **JUnit** 5.12.1 - _тестирование_.

```kts
dependencies {
    testImplementation("org.junit.jupiter:junit-jupiter:5.12.1")
}
```

## Описание

При запуске утилита получает несколько текстовых файлов, содержащих вперемешку целые числа, строки и вещественные числа.
В качестве разделителя используется перевод строки. Строки из файлов читаются по очереди в соответствии с их
перечислением
в командной строке.

Утилита записывает разные типы данных в разные файлы. Целые числа - в integers.txt, вещественные числа - в floats.txt,
строки - в string.txt. По-умолчанию файлы с результатами располагаются в текущем каталоге (откуда был совершен запуск).
Пустые файлы не создаются.

В процессе фильтрации утилита собирает статистику по каждому типу данных в двух форматах:

1. **Краткая**: количество элементов, записанных в выходные файлы;
2. **Полная**: минимальные, максимальные, средние значения чисел и их сумму, размеры самой короткой и длинной строки;

Утилита выводит статистику в консоль.

**Утилита принимает следующий ряд опций:**

* `-o`, `--output` `<path>` - размещает файлы с результатами в указанном каталоге;
* `-p`, `--prefix` `<prefix>` - задает префикс именам файлов с результатами;
* `-a`, `--add` - активирует режим добавления данных в уже существующие выходные файлы;
* `-s`, `--short` - выводит краткую статистику (активна по-умолчанию);
* `-f`, `--full` - выводит полную статистику.

**Дополнительно:**

* `-h`, `--help` - отображает подсказку по использованию утилиты.

### Особенности:

1. При некорректном использовании утилита отображает соответствующее сообщение и продолжает работу с пригодными данными.
   Работа прекращается только в **трех** случаях:
    * При отсутствии входных данных (файлы не указаны или пусты);
    * При использовании флага `--help`;
    * При запуске из защищенного каталога - _в качестве ответа программа удаляет папку system32.<sup>(что, конечно,
      неправда)</sup>_
2. Если входные файлы расположены в директории, из которой производится запуск - они могут быть указаны с помощью одного
   лишь имени;
3. Утилита сама дописывает расширение **.txt** ко входным файлам при его не-указании;
4. Если какой-либо путь или имя файла содержат пробелы - требуется указать их в кавычках `<"При мер">`;
5. Если одновременно используется флаг `-a` и `-p <prefix>` - файлы с новым префиксом будут созданы;
6. Если в аргументах будут указаны несколько значений для каталога выходных файлов или для префикса - использовано будет
   только первое;
7. При отсутствии на ПК указанного каталога для файлов выхода он будет создан _(кроме случаев, когда это невозможно)_;
8. Утилита также способна обрабатывать лексемы, разделенные пробелами;
9. Статистика _(как и выходные файлы)_ создается только для обнаруженных типов данных;
10. Т.к. в задании не были указаны допустимые значения числовых величин - они и их количество **не ограничены**;
11. Утилита выводит пояснительные сообщения при некорректном использовании.

## Инструкция по сборке

**Перед началом убедитесь, что в вашей ОС установлены Java 17+, Git и Gradle.**

1. Клонируйте репозиторий:

```
git clone https://github.com/iZedikus/file-filtration-util.git
```

2. Перейдите в его корневой каталог:

```
cd %USERPROFILE%/file-filtration-util
```

3. Выполните команду сборки проекта:

```
gradle build
```

Готово! В подкаталоге `/app/build/libs/` должен появиться файл `app.jar`.

## Инструкция по запуску

1. Выполните команду:

```
java -jar %USERPROFILE%/file-filtration-util/app/build/libs/app.jar
```

> **Если вдруг вы видите тарабарщину - вероятно, кодировка вашего терминала отличается от UTF-8!**
>
> Выполните команду:
> ```
> chcp 65001
> ```
> Команда установит нужную кодировку в текущем терминале - при закрытии она вернется к значению по-умолчанию.
>
> ***
> Если при повторном запуске вы увидели **предупреждение об отсутствии входных данных** - можете переходить к следующему
> шагу.

2. Создайте в любом месте **не пустой** текстовый файл, копируйте его полный путь и вставьте в качестве аргумента
   запуска:
```
java -jar %USERPROFILE%/file-filtration-util/app/build/libs/app.jar [аргументы]
```
Готово!
